# Erwu painted garden atlas

`erwu-romantic-atlas.png` is a 1254 × 1254 RGBA atlas (about 1.6 MB), generated with the built-in image-generation tool on 2026-09-27 for the user's requested Romantic-era naturalist sketch direction. It depicts the same grey, amber-eyed cat in eight walking frames and eight still/action poses. The original user reference image is not included.

The game crops explicit source regions because the generated sheet is not a mechanically perfect grid. Alpha bounds are scanned once on load; source proportions are retained and feet are aligned to the ground. The walk cycle is driven by distance, with a short dissolve between frames. Reduced motion holds a representative frame. Loading/decoding failure falls back to the existing procedural drawing, with back stripes removed.

This is an art-direction prototype. The eight walking drawings are generated rather than a hand-cleaned animation sequence. Blink, expression and open-mouth yawn variants are not yet in the painted atlas; greeting/attention still use the seated pose and the original behavior timing. The run and game-over rendering retain the original compact procedural artwork. None of these assets has been deployed.
