## Timing correction and limits

Previously the 22-second cutoff used wall time while pollen used scaled time: 3× could receive up to 66 seconds of simulated activity. It now uses **22 simulation seconds at either speed**, with 1/120-second steps for pollen, power-ups and wash-back tweens. Bee movement and dandelion scatter use a per-shot random stream separate from decorative drawing. This is a gameplay timing correction, not just a button relabel. Fixed-step integration can change individual trajectories relative to the old variable-step build; no longitudinal difficulty or run-length claim is made.

Aiming describes the current first contact with existing collision geometry, sampled within half a CSS pixel. It does not predict bounces, wash-back motion or random scatter. Labels and help are visual aids, not a complete nonvisual tactical interface.

Slices 7 and 8 remain separate: richer garden-return progress, replanting below the current 5% threshold, formative new-player testing and native-device acceptance. The README now states the existing replanting threshold accurately; this pass does not change that ownership rule.
